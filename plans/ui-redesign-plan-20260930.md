# NexArtMS 前端改版方案与验收标准 v2

2026-09-30｜已实施。以下数值保留为设计目标；实测证据、已通过项和未测边界见 [前端改版验收记录](../docs/reports/ui-redesign-20260930/README.md)。

## 1. 目标与边界

以专业影视风格支撑简约操作：导入后先看结果，按对象按需修正。采用唯一默认布局，不提供多种工作台模式。第一轮保留全部实际可达功能与领域状态，只改变布局、样式和交互呈现，不新增业务审批、设置前置、API 或模型能力。设计示意不充当真实分析结果。

当前重复大卡片、过高顶栏、10/11px 文字及重复错误提示影响观看。镜头导航与镜头时间轴合并，取消常驻编辑表单和关键帧墙。`?lab=rig` 当前仍进入项目主页；独立刚性实验页不可达，恢复入口另定范围。

## 2. 唯一布局与四层披露

统一顶栏：项目名称、拉片／人物／三维还原、项目菜单。主画面优先，底部只有一个“镜头条”；播放器原生进度留在播放器内，不再创建额外时间轴。

页面层级仅保留“项目首页 → 项目工作页”。拉片、人物、三维还原是同一项目的三个工作视图，共用当前镜头与播放位置，不重新进入流程、不重复选择素材。导入后直接进入可观看结果；配置缺失只影响相应自动任务。

镜头条默认缩略图，展开“镜头表”时替换同一组件的呈现，二者互斥。1440×900 顶栏约 56px、镜头条 112–136px，其余留给画面；默认没有左侧镜头导航和固定右侧详情栏。≤768px 修正面板改为抽屉，不挤压为多列。

| 层级 | 显示内容与触发 |
|---|---|
| L0 观看 | 画面、基本播放、唯一镜头条、短状态；没有展开编辑面板。 |
| L1 选中 | 选镜／人物后出现当前对象摘要与一个“修正”；摘要无需表单。 |
| L2 主动修正 | 点击“修正”打开单个上下文面板：基本字段、保存、撤回本次草稿、未保存提示。桌面临时右侧面板，窄屏抽屉。 |
| L3 高级 | 明确命名的“更多工具”内访问现有切点、相机、原始结果等；设置、导出放入项目菜单。任务由唯一处理状态摘要直接打开。 |

重要错误、真实进度、未保存状态始终可见，并给一个针对性下一步，不藏入高级层。保存成功回到摘要；切页或关闭面板不得静默丢失草稿，撤回只针对明确标注的本次编辑。

## 3. 逐页设计

| 页面 | 简约呈现 |
|---|---|
| 项目／导入 | 紧凑项目列表，封面、名称、时间、真实状态；默认主操作仅“导入素材”。失败保留现有恢复路径。 |
| 拉片 | 视频与唯一镜头条；选中后显示本镜摘要，修正时才展开字段。分析／重试入口说明实际处理范围。 |
| 人物 | 先展示人物目录；点人后显示摘要、出场信息，并将同一镜头条筛为此人相关镜头；关闭筛选返回全部镜头，不另建出场列表。 |
| 三维还原 | 默认原片／还原对照与同一镜头条；视角只有一个选择器。角色／相机选中并主动修正后才展开参数。无结果显示真实原因。 |
| 设置／任务 | 设置从项目菜单进入；处理状态摘要直接打开任务，避免再设置第二个任务入口。设置按组，错误就近说明；任务详情主动展开。 |
| 报告／交付 | 项目菜单明确区分“拉片报告”与“三维交付包”，显示实际范围、缺失项与生成结果，沿用现有格式。 |

人物补标、切点、原始输出、相机校准、外观／身高及现有可选正式确认仍可发现；保留业务原有前置条件，普通浏览、初稿更新与导出不新增确认门槛。长内容按需展开，禁止用不同镜头图片填充缺失结果。

报告、分析数据及三维交付在项目菜单按实际可用产物显露。任务失败从状态摘要进入即可看到原因与重试。产生候选切点后，当前上下文立即出现“采用候选版本”及下游影响；人物目录保留未归属入口与按需批量操作。合并、忽略、删除、采用新版本等明确表达作用，不共用含糊的“确定”。

## 4. 视觉与交互规范

背景／面板／控件：`#101216`／`#181B20`／`#22262D`；正文／辅助：`#ECEEF2`／`#A8B0BD`；动作和选中：`#78ACFF`；状态绿／琥珀／红：`#7DD3AB`／`#F0C36E`／`#FF9696`。强调色集中用于当前选择与动作，状态同时用文字表达。

正文 14px、辅助 12px，时间码用等宽数字；常用控件高 32/36px，触控区域≥44×44px；圆角 6/8/12px，间距 4/8/12/16/24/32px。统一组件及焦点状态，尊重减少动态效果偏好。

默认每工作页的工作提交主操作≤1；选镜、播放、导航不计入提交按钮。同功能按钮不同时出现两处。进入修正后“保存”为唯一主操作，“撤回本次草稿”为次要操作。输入区不抢快捷键；失败保留输入，重复点击不重复提交；跨页使用统一源视频时间基准，筛选不隐式跳转或写回业务数据。

## 5. 验收矩阵

| 编号 | 可复现目标标准（实测状态见验收记录） |
|---|---|
| A01 范围 | 实际可达页面与操作逐项对照，无入口丢失、断链和假能力；旧记录按现有兼容规则显示。 |
| A02 桌面 | 1440×900、1280×800 截图无溢出／遮挡；原片保留真实比例与边缘，默认主要画面区域宽≥480px。 |
| A03 窄屏 | 1024×768、768×1024、390×844 下观看、定位、主操作可达；200% 文字缩放不丢内容；保留必要画布二维操作。 |
| A04 层级 | 逐页截图对照 L0–L3；只有主动操作才进入修正／高级层，不以设置或审批阻挡普通浏览。 |
| A05 排版 | 正文≥14px、辅助≥12px；40 字中文名称、重名人物与长错误不遮挡操作，截断可展开。 |
| A06 对比 | 普通文字≥4.5:1，必要控件边界及焦点目标≥3:1；测量颜色组合，状态不只靠颜色。 |
| A07 点击 | 控件达到约定高度，触控区域≥44×44px；图标有可读名称，不能仅靠悬停识别。 |
| A08 焦点 | 键盘流程录像：焦点可见，弹窗限制焦点，关闭返回入口；正常输入不触发快捷键。 |
| A09 空态 | 无项目／镜头／人物／三维结果分别截图，准确说明并给现有可用下一步。 |
| A10 加载 | 延迟与重复点击测试：实际阶段、无伪百分比；任务只创建一次，刷新不整页闪空。 |
| A11 失败 | 混合成功／失败／待处理仍可浏览成功结果；缺 Key／权重／请求失败可定位，重试范围明确。 |
| A12 冲突 | 临时项目制造版本冲突和提交失败：输入保留、原因可读、可恢复，无静默覆盖。 |
| A13 同步 | 零／非零起点媒体各≥10 个跳转点及跨页录像；暂停误差≤一个源帧时间间隔，播放高亮与画面一致。 |
| A14 数据 | 浏览／切页／筛选前后业务数据与版本一致；现有报告与交付可打开，UI／日志不暴露完整 Key。 |
| D01 唯一导航 | 每页最多一个镜头条；缩略图／镜头表互斥，播放器内进度之外无额外时间轴，无重复出场列表。 |
| D02 默认简约 | 打开三页均无展开编辑面板、固定详情栏或关键帧墙；只有一个默认布局，无模式轮播。 |
| D03 动作预算 | 默认工作提交主操作≤1，同功能按钮不重复；修正面板只有保存为主操作，未保存提示可见。 |
| D04 上下文／范围 | 同机连续切页、筛选、开关面板 20 次：当前时间与选择不意外重置，草稿不丢；镜头条范围始终唯一并标明“全部／此人”，清除即恢复全部。 |
| D05 可发现 | 任务通过状态摘要一次打开；设置、导出经项目菜单两次到达。高级工具从选中对象的修正面板进入，面板内菜单深度≤2；所有操作明确命名且可达。 |
| D06 恢复可见 | 加载、失败、冲突、未保存四类状态在观看层可见；每项提供一个明确下一步，恢复不要求寻找隐藏表单。 |

对比度参考 [W3C Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)，布局参考 [Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)，点击参考 [Target Size Minimum](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)。44px 是本项目目标；不宣称完整无障碍认证。

## 6. 夹具、路线与完成定义

隔离夹具覆盖空态、长名称／重名、200 镜头、横／竖版、加载／部分失败、缺配置、版本冲突、零／非零起点、有／无三维结果；真实 57 镜头项目仅只读浏览。外观验收不触发付费调用，不修改用户业务数据；性能以同机改版前基线记录，不承诺未测帧率。

1. 确认唯一结构与视觉基线，提供三页及管理／设置示意。
2. 建立公共组件、镜头条与四层披露，不新增业务功能。
3. 整合正式页面与低频入口，保留真实状态和现有操作。
4. 执行 A01–A14、D01–D06，完成构建、原测试、截图及录像，修正发现的问题。

完成：功能对照与验收证据可复现，核心操作、数据安全、同步无阻断问题；未测项及外部 Provider／权重限制单列，不记作通过。
