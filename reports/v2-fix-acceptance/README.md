## 还原质量的真实结果

| 指标 | 最终值及解释 |
| --- | --- |
| 自动切镜 | 57 镜；与项目已有 47 镜参考表进行 ±2 帧一对一匹配，召回 **100%**，精确率 **82.1%**。这是单个样片结果，并非全部素材的质量保证 |
| 人物轨迹 | 121 段 |
| 动物轨迹 | 13 段 |
| 自动人物身份 | 96 个候选；没有跨镜身份真值验收，存在过度拆分 |
| 自动动物身份 | 11 个候选；仍有疑似误检，不能当作已确认个体数量 |
| 有动作文件的轨迹 | 11 条；文件存在不代表整条出场均有效 |
| 人物可见时间 | 70.125001 主体秒 |
| 动物可见时间 | 1.125002 主体秒 |
| 有效动作时间 | 3.583330 主体秒 |
| 总体有效动作覆盖 | **5.0%**；人物 **5.1%**，动物 **0%** |
| 相机 | 57 镜均缺少有效原片相机解，使用明确的默认相机 |
| 最终初稿状态 | `ready_with_issues`，234 项问题记录，包含动作区间缺口、未绑定动物和相机缺失 |

“主体秒”按每个主体可见时长相加，两人同时出现 1 秒会计为 2 主体秒。它不是影片播放时长。

第一轮服务曾显示 7.3%。最终统一空/坏采样的最近帧有效区间后，结果为 **5.0%**，本报告以最终值为准。额外把 `timeline.json` 实际可见且已求解的时间积分，与服务端统计逐项核对：人物可见时间完全一致，有效时间只差 **1 微秒**（边界取整）。因此较低数字反映实际显示内容，而不是文件条数。

全时长 MP4 是本次验收生成的初稿预览，画面上会显示已求解/占位与默认相机状态。它证明时间线能完整输出，不代表缺失动作已经还原，也不代表产品内的视频导出按钮已经完成。

- 原片连续运镜、可靠的世界坐标走位、接触与遮挡还原；当前人物落点是单目近似估算。
- 产品内一键视频渲染、Blender/Maya/Houdini 实机回读及 V2 A01–A18 的完整质量验收。

下一步最有价值的是提升有效动作覆盖和主体识别准确率，再推进动物与相机完整链路。仅继续改善流程提示，不能解决目前 5.0% 的真实覆盖率。
