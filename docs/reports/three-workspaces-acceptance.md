# 三功能简化验收记录

日期：2026-09-30。对应 [实施计划](../../plans/three-workspaces-simplification.md)。

## 本轮结果

首页选视频后自动使用文件名创建项目。项目内固定三个并列入口：拉片、人物、三维还原。观看结果是默认状态，修改与技术设置放在相关结果附近，用户主动展开后才出现。

- 拉片：视频、证据帧、镜头表和当前镜头摘要；“修改本镜”“调整切点”、来源和完整词表按需展开。
- 人物：按已有名称/描述进行片内筛选；默认显示人物，动物单独查看；点击人物查看出场，并可定位同一源时间的拉片/三维。外观推断显示“暂定匹配”。
- 三维：原片与 Three.js 对照，默认自由观察；可切镜头视角或俯视。角色、相机和导出收进次级工具；估计相机与缺动作按真实状态提示。
- 设置：已配置模型直接显示当前选择与密钥保存状态；修改密钥、高级连接参数、连接诊断默认关闭。正式核对版本不是预览或生成现有交付包的前提。
- 后端：人数不包含动物；更新还原检查有效人物、绑定和姿态产物并防止重复入队；明确请求重新检测时可续跑既有整理/动作/相机链。

## 运行状态与边界

- 新静态页面已在 `http://127.0.0.1:8199/` 生效。最后补充的后端恢复参数与前置校验需要重启 Node 服务；自动审批拦截了停止旧进程/启动新进程的操作，因此未宣称当前进程已加载最终 router。源码、构建及隔离 HTTP 回归已通过。
- 片内检索使用既有名称和描述，不是未知演员身份识别。人物归属的既有启发式算法没有在本轮重写。
- 三维仍是人物动作和相机的近似白模；动物动作、从视频生成真实场景和 MP4 渲染不属于现有能力。导出继续是已实现的 GLB 与数据交付包。
- 本轮修正了播放时钟的源 PTS 换算；后端末镜边界和导出时间表既有的非零 PTS 口径问题未在本轮重构，不能以播放器 fixture 代替端到端非零 PTS 导出验收。
- 切点采用后可按需重新检测；已有人工决定保护可能拒绝全量检测，应按反馈修正具体出场。本轮未实现按变化镜头自动局部重算，也未改变人工版本校验。
