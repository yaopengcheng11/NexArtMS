## 独立复核修复记录

- 候选重试必须保留未采用边界与人工修正，不能静默退回活动镜头；来源运行和版本不匹配返回 409。
- provider/model/schema/prompt 改变后真正重新生成机器语义；同运行历史来源归档，人工覆盖保留。
- 重新拆镜时仍抽取继承的主体参考帧，即使它不再位于新镜头的固定采样点。
- 修改活动切点后首次 GET 即显示旧拉片 stale，旧报告接口返回 409；原始证据保留。
- 删除项目同时删除运行与单镜标注，防止 SQLite 遗留人工语义和主体描述。
- 编辑及采用候选后重新校验并刷新报告，下载内容与界面一致。
- 未配置模型时语义检查明确 skipped，不生成每镜重复的“字段未填”错误；源帧和证据错误仍必须失败。

## 尚未通过的产品验收

需要用户明确的视觉供应商、模型和端点配置，随后再跑完整样片，逐镜核对动作、景别、运镜、主体身份及水印误识别。代码可以接收真实模型输出；本机 fixture 只证明流程与故障处理，不证明视觉判断正确。

模型自动修正后的参考 47 镜、人物 A/B 跨镜一致性、动物个体识别均未宣称通过。后续叙事分组、动物代理/动作与 Three.js 高还原度仍是后续阶段，本轮只交付素材导入后的拉片环节。
