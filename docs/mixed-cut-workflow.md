# 混剪素材：角色归并与可选场景

> 状态：产品需求与实施规格，尚未实现。本文更新了原计划中“单一场景优先”和“原片人物与三维角色一一对应”的假设。现有 JWM 工作台和流程演练仍是样片原型。

详细工作包、框架取舍与量化验收见 [混剪视频还原开发计划](development-plan-mixed-cut.md)。

## 目标与流程

用户导入剪辑视频后，系统按镜头找出画面中的**人物出场候选**。用户回看并修正候选，把不同镜头中由不同演员、服装或外观呈现的人物指定为同一个**成片角色**，也可以拆分、忽略路人或补标漏检。后续相机、姿态和动作还原使用已确认的映射，让目标角色在全片保持一致，同时保留每次出场自己的动作和镜头时间。

1. **导入与分析**：上传原视频；探测时长、尺寸、帧率与时间戳，生成预览、镜头边界、人物检测和镜内轨迹。显示进度与失败原因。
2. **角色确认 / 人物归并**：按镜头展示各轨迹的多张截图、出现区间和原片回看。用户创建目标角色，把轨迹归并、拆分、改派、忽略或补标。
3. **角色资产**：确认目标角色名称、颜色、比例和代表参考；骨架与外观保留版本。
4. **相机与动作**：每次出场保留自己的镜头、时间、相机和动作观测；还原时使用归并后的角色资产。跨切镜不默认连接空间轨迹。
5. **审查与交付**：逐镜检查角色、人数、动作与相机，导出视频及角色、动画、相机数据。

自动检测只能给出可修正的候选，不能自动决定叙事身份。快切、背影、遮挡和多人重叠可能漏检或错配，因此必须支持回看及手工修正。

## 场景选项

导入时选择 `proxy` 或 `reconstruct`。`proxy` 只建立尺度、坐标、地面和必要接触代理，输出可隐藏场景；`reconstruct` 还要制作并验收可见场景。两种模式均需检查相机和动作。未要求场景的状态记为 `not_requested`，不能写成“场景已通过”。相机数据须脱离可见场景资产独立保存。

## 数据关系

| 实体 | 主要数据与约束 |
| --- | --- |
| `MediaSource` | 原片、哈希、预览、时长、尺寸、时间基和帧映射；任意视频不能固定按 24 fps 计时 |
| `Shot` | 原片起止时间与帧边界；切镜结果允许用户修正 |
| `SourceTrack` | 镜头、时间范围、人物框/姿态观测、裁剪图、置信度；只表示素材中的一次连续出场 |
| `CharacterAsset` | 稳定 ID、名称、颜色、比例、骨架和版本；表示成片角色，不等于原片演员 |
| `CastingBinding` | 轨迹 ID、目标角色 ID 或 `ignored`、状态和版本；多条轨迹可指向同一角色，不改写原始观测 |
| `ActorInstance` | 镜头、轨迹、目标角色和动作引用；保留每次出场的独立动作、位置和时间 |
| `AnalysisJob` | 输入与模型版本、状态、进度、错误和输出；重分析不覆盖人工归并 |

同镜同时出现的两条独立轨迹若被归为同一角色，应提示冲突；确有分身或镜像时由用户明确允许。修改归并会使相关动作绑定、预览和导出结果过期，原视频和观测无需重跑。修改骨架比例还须重新求解动作重定向与接触。

## 首个可交付闭环

- 在独立项目目录上传受支持的视频，生成可播放预览；不覆盖 JWM 数据。
- 自动产生可回看的镜内人物轨迹候选，标出来源和置信提示；空镜允许没有人物。
- 用户能归并、拆分、忽略、补标和修改目标角色；刷新、重启后结果仍一致，旧版本写入返回冲突。
- 所有有效候选已绑定或明确忽略后，才允许正式确认映射；确认记录绑定输入视频、分析结果和映射版本。
- 逐镜角色清单及后续动作输入实际读取确认映射，不再使用写死的 P1/P2。测试须覆盖不同演员归为同一角色、同一演员分配为不同角色、多人同框及漏检补标。
- 关闭可见场景仍可进入相机与动作任务；原 JWM 演练继续工作。

首版先解决镜内检测与跟踪；跨镜相似分组只能作为建议。模型应在真实混剪样本上评估召回、错配、速度、资源和许可证后固定版本。模型不可用时显示真实失败，不能以 JWM 卡片冒充分析结果。

## 现有实现与边界

当前 `server.mjs` 只接收小型 JSON，没有视频上传；`project-store.mjs` 是单个 JWM 项目；`src/Rehearsal.tsx` 的 P1/P2 只是演练状态。实现需先建立独立项目、媒体与角色映射，并保留旧 `data/` 的兼容读取；不能直接令现有 `scene` 为 `null`。正式角色确认须与演练 `demo_passed` 分开。

本规格不表示任意视频的三维动作和相机求解已完成。单目混剪存在遮挡、深度与尺度歧义，正式结果需要可追溯观测、人工确认及逐镜质量检查。
