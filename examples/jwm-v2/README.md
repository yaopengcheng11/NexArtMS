# JWM · Three.js 白模复现 V2

根据 `jwm.mov` 重建的实时白模预演，50.125 秒、47 镜、24 fps，画布固定为 1280 × 720。橙色为灰绿衣/褐裤/白鞋的 P1；蓝色为灰蓝衣/黑鞋的 P2。

## 打开

这是新工作台保留的旧版实时预演示例。在本目录安装依赖并构建后运行：

```sh
npm ci
npm run build
node serve.mjs
```

打开 <http://127.0.0.1:8197/>。仓库包含源码、姿态数据和原片预览；构建后播放不需要下载模型或调用生成服务。新五阶段工作台从仓库根目录启动，见 [主 README](../../README.md)。

## 操作

- 空格：播放 / 暂停；左右方向键：切换镜头。
- 上一帧 / 下一帧，或 Shift + 左右方向键：逐帧检查。
- 输入秒数后跳转，会吸附到原片帧。
- 并排对照：两侧使用相同画幅和显示尺寸。
- 叠加对齐：把同一个原片播放器半透明叠在三维画面上，可调整透明度。
- 自由视角：拖动旋转、滚轮缩放；再点一次恢复原片构图。

## 准确度边界

这是优先匹配原片机位的三维预演。屏幕关节位置来自自动检测与人工估计，不是专业动捕；快速遮挡、衣服内关节、手指、接触细节仍会有偏差。纵深、被遮挡身体和场景背面没有实测依据，自由视角显示的是估计结构。背景轮廓遮挡区采用邻列插值，墓墙细节为简化白模。

原片仅用于右侧/叠加对照和原声，未贴到三维人物或场景上。

## 可编辑数据与源码

- `src/scene.js`：白模、三维肢段、深度估计、地面约束和背景。
- `src/pose-data.json`：逐帧人物坐标及镜头布局。
- `src/background-data.json`：逐帧山坡边界。
- `src/shots.js` / `shots.json`：已纠正的镜头时间与描述。
- `data/raw.json`：原片自动检测结果；`data/source-layout.json`、`data/extra-overrides.json`：人工校正。
- `pose-audit.json`：逐镜检测、补帧、人工校正及尺度计算记录。置信度和数据覆盖率不等于动作准确率。

修改源码后：

```sh
npm ci
npm run build
```

修改人工关节数据后，先运行 `npm run rebuild:poses`，再构建。`npm run check` 检查全部帧、切点和实际三维网格变换是否有效。

技术来源：[Three.js](https://threejs.org/)、[Ultralytics 姿态检测文档](https://docs.ultralytics.com/tasks/pose/)。检测在本机完成；网页播放不依赖检测模型。
